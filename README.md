## 📌 Project Overview
**Random-Joke Generator** is a lightweight single-page web app that serves up fresh one-liners at the click of a button.  
I built it while learning ES6 JavaScript and the Fetch API as a fun way to practise working with HTTP requests and DOM manipulation. :contentReference[oaicite:0]{index=0}

---

## ✨ Key Features
| Feature | Description |
| ------- | ----------- |
| 🔄 **New Joke** | Fetches a completely new joke from *icanhazdadjoke.com* via Fetch-API. |
| 📋 **Copy to Clipboard** | One-tap copy so you can share the laugh instantly. |
| 💾 **No Back-End Needed** | 100 % client-side – just open `index.html` and go! |
| 📱 **Responsive Layout** | Clean CSS so it looks good on phones, tablets, and desktops. |
